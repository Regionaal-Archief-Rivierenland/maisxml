# maisxml

Python library om met MAIS XML te werken.

# Documentatie

Voorbeeld code, beschikbare functies en functie-documentatie kun je hier vinden:

https://regionaal-archief-rivierenland.github.io/maisxml/

# Installatie

```
git clone git@github.com:Regionaal-Archief-Rivierenland/maisxml.git && sudo pip install . 
```

(of zonder `sudo` als je het voor je gebruiker wilt houden, of met `uv`, etc.)
